# VARA

أداة سطر أوامر محلية: تعطيها **مهمة** أو **هدف**، فتعمل حتى تتحقق شروطها، ثم **تثبت** النتيجة بأدلة مسجّلة — لا بادعاء النموذج. بدون اشتراك شهري ولا منصة مغلقة: تعمل على جهازك بمفتاح مزوّدك أنت.

> هذا مستودع خاص. إذا كان هذا أول دخول لك — ابدأ من هنا، ثم انتقل إلى الوثائق الثقيلة عند الحاجة.

---

## الفكرة في 30 ثانية

- **المحرك واحد**: `task` و`goal` يختلفان في سياسة الإكمال والميزانية فقط، لا في الكود.
- **الإنهاء يُثبت ولا يُفترض**: النموذج يستدعي أداة `complete`، ثم **المحرك نفسه** (لا النموذج) يشغّل أمر التحقق ويسجّل رمز الخروج. فشل التحقق = المهمة لم تكتمل.
- **الصلاحيات تُفرض على مستوى الأدوات**: وضع `plan` يمنع الكتابة وـ shell فعلياً برمجياً، وليس بطلب من النموذج.
- **الأسرار لا تظهر أبداً**: مخزن مشفّر (AES-256-GCM بمفتاح مربوط بالجهاز)، وكل المخرجات تمرّ على ممحّ أسرار قبل حفظها.
- **التمني الصادق**: إن لم يُعرف تكلفة استدعاء، تُسجَّل `null` (غير معروفة) — لا تُسجَّل صفر أبداً.

## البدء السريع (5 دقائق)

```bash
npm install
npm run build
npm link            # يوفّر الأمر `vara` عالمياً

vara config init    # يكتب ~/.vara/config.json — عدّل المزوّد فيه
vara secret set KTAI_API_KEY    # يخزّن المفتاح مشفّراً (يُسأل عن القيمة ولا تظهر)

vara               # يفتح واجهة TUI في المجلد الحالي
```

الحد الأدنى لتشغيل حقيقي: `config.json` يشير إلى مزوّد OpenAI-compatible أو Anthropic، ومفتاح مخزّن في الـ vault (أو متغيّر بيئة كبديل).

## أوامر سطر الأوامر

| الأمر | الوظيفة |
| --- | --- |
| `vara` | TUI: يفتح آخر جلسة في المجلد أو شاشة الترحيب |
| `vara resume <id>` | استئناف جلسة محفوظة |
| `vara sessions [--all]` | جلسات هذا المجلد (أو كل الجلسات) |
| `vara run "<المهمة>" [--goal] [--plan] [--verify "npm test"]` | تنفيذ بلا واجهة (للأتمتة) |
| `vara secret set/list/delete` | إدارة المخزن المشفّر |
| `vara config init/show` | الإعدادات (لا تُعرض الأسرار أبداً) |

## اختصارات الواجهة (المهمة فقط)

| الاختصار | الفعل |
| --- | --- |
| `Enter` | إرسال — اللصق متعدد الأسطر يحتفظ بسطوره |

| `Ctrl+K` | لوحة الأوامر |
| `Ctrl+N` | جلسة جديدة |
| `Alt+← / →` بين التبويبات · `Ctrl+W` إغلاق تبويب · `Ctrl+B` الشريط الجانبي · `PgUp` تمرير · `Esc` إغلاق طبقة أو قطع التنفيذ (مزدوج) | |

القائمة الكاملة داخل الأداة: `/help`.

## قواعد هذا المشروع

1. **لا أسرار في المستودع أبداً** — `.env` محجوب، والمفاتيح تُخزَّن في الـ vault المشفّر أو متغيّرات البيئة.
2. **بوابات التحقق إلزامية قبل كل push** — `npm run check` يجب أن يكون أخضر بصراحة، والفشل يُبلَّغ كما هو.
3. **unknown ≠ 0** — القيمة غير المعروفة تُسجَّل غير معروفة، لا صفراً.
4. **الإثبات بالأدلة** — سلوك جديد أو إصلاح = اختبار يفشل قبل الإصلاح وينجح بعده.
