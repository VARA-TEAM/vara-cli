# VARA وHermes Agent — ما تعلّمناه وأين نقف

[English](../HERMES-COMPARISON.md) · **العربية**

[Hermes Agent](https://github.com/NousResearch/hermes-agent) (رخصة MIT) أكمل وكيل مفتوح نظرنا فيه. هذه الصفحة حصيلة قراءة README وقائمة أدواته وتوجيهاته (أكتوبر 2026). نأخذ **الأفكار** ونعيد كتابتها بشيفرتنا؛ لم يُنسخ شيء. هي خريطة لا وعد: "ناقص" يعني ناقصاً اليوم.

المفتاح: ✅ موجود · 🟡 جزئي · ❌ ناقص · ➖ ليس هدفاً عمداً.

## موثوقية الوكيل نفسه

| Hermes | VARA | ملاحظة |
| --- | --- | --- |
| يرفض التعديل إن تغيّر الملف منذ قراءته | ✅ **جديد** | `src/tools/file-guard.ts`؛ يُطلب من الوكيل إعادة قراءة الملف. |
| نقاط استعادة للملفات والتراجع | ✅ **جديد** | كل كتابة وتعديل وحذف يُحفظ قبلها؛ `/undo [n]` و`/checkpoints` (الطرفية) و`/undo` (المتصفح). يبقى بعد إعادة التشغيل. الملفات فوق 2 ميغابايت لا تُحفظ ويُقال ذلك. |
| البحث في الجلسات القديمة | 🟡 **جديد** | `session_search` يفحص أحدث 80 جلسة في المجلد بالكلمات التي تعطيها. عند Hermes فهرس نصي كامل مع تلخيص؛ عندنا فحص بسيط. |
| تعديلات متسامحة (مطابقة تقريبية وإصلاح الهروب) | 🟡 | نتسامح مع فرق CRLF/LF فقط. |
| توجيهات تدفع النموذج للفعل لا الإعلان | ✅ **جديد** | فقرة قصيرة "استعمل ما عندك" وقاعدة أقوى لتحويل الدردشة إلى مهمة. لم تُقَس بعد بـ`vara eval` على نموذج حقيقي. |
| حفظ مخرجات الأدوات الطويلة واسترجاعها | ✅ | `tool_output`. |
| أوضاع موافقة ذكية / "yolo" | 🟡 | الموافقة لكل إجراء؛ بلا قائمة سماح متعلَّمة. |

## التكلفة والسياق

| Hermes | VARA | ملاحظة |
| --- | --- | --- |
| ضغط السياق | ✅ | `/compact` والضغط التلقائي ومحرك التكلفة 2. |
| مخططات أدوات كسولة (`tool_search`) | ❌ | تقلّل التوجيه في كل دور أكثر. خطوة تالية جيدة. |
| تجميع استدعاءات الأدوات المستقلة | ✅ | قاعدة في التوجيه + تنفيذ متوازٍ. |

## أين يعمل ومع من يتكلم

| Hermes | VARA | ملاحظة |
| --- | --- | --- |
| بوابة رسائل (Telegram وDiscord وSlack وWhatsApp وSignal) | ❌ | لم تبدأ. Telegram وDiscord أولاً إن أردتَ. |
| بيئات تنفيذ (Docker وSSH وModal وDaytona…) | ❌ | الأدوات تعمل على المضيف. لازمة قبل أي عرض مستضاف. |
| مهام مجدولة تُسلَّم نتيجتها إلى محادثة | 🟡 | `vara schedule` يشغّل ويسجّل بلا تسليم. |
| سجل عمليات خلفية بمخرجات | 🟡 | خوادم التطوير عبر `preview`؛ بلا shell خلفي عام. |
| واجهة ويب + طرفية | ✅ | كلتاهما مع جدول تكافؤ ([ARCHITECTURE.md](ARCHITECTURE.md)). |
| حزمة أندرويد (Termux) | ❌ | طريقتهم للهواتف؛ وواجهة المتصفح تعمل على الهاتف أصلاً. |

## المهارات والأدوات والأمان

| Hermes | VARA | ملاحظة |
| --- | --- | --- |
| مهارات ينشئها الوكيل ويحسّنها | ✅ | يقترحها الوكيل وتوافق أنت. |
| متجر مهارات ومدقّق وفحص أمني للمهارات | ❌ | لا نثبّت مهارات الغير تلقائياً. |
| توافق agentskills.io | ❓ | لم يُفحص. |
| MCP مع OAuth | 🟡 | منجز ومُختبَر على خادم وهمي محلي فقط. |
| فحص ثغرات الحزم (OSV) قبل التثبيت | ❌ | |
| سلامة الروابط والمسارات وحجب الأسرار | ✅ | |
| المتصفح وسطح المكتب | ✅ | سطح مكتب ويندوز متحقَّق منه؛ ماك ولينكس لا. |
| الصوت وتوليد الصور والفيديو | ➖ | ليست أول ما يحتاجه وكيل برمجي. |
| لوح كانبان للوكلاء | 🟡 | `delegate` بأدوار وتبعيات بلا لوح مشترك. |

## ما نفعله بعد ذلك، بهذا الترتيب

1. قياس تغييرات التوجيه والضغط بـ`vara eval` على نموذج حقيقي ونشر الجدول.
2. مخططات أدوات كسولة (`tool_search`).
3. بيئة Docker لتنفيذ الأدوات.
4. جسر Telegram مع ربط المالك وموافقات داخل المحادثة.
5. عمليات shell خلفية وتسليم نتائج المهام المجدولة.
